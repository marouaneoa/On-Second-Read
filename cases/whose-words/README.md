# Whose words count?

Ravi applies for a museum visitor-services job. The practical exercise asks candidates to write directions for a visitor who has never used the ticket machine. The panel receives a short observation from the trial. One reviewer asks whether a visitor could complete the task. The other is interested in how Ravi learned to write.

## What the panel agreed to assess

Clear instructions means a first-time visitor can collect a ticket without help. The exercise has one published criterion. The application materials do not request a particular degree.

## Read the file

**p1 · Visitor trial**

A visitor who had never used this machine read Ravi’s card. It said to select a language, tap Collect booking and enter the six digits on the confirmation slip. The visitor followed the three steps, collected the ticket and joined the entrance queue. The observer stayed behind the marked line and gave no prompts.

## Listen to the reviewers

**Reviewer A · cites p1**

I watched for the moment the visitor might need a hint. The observer records that there were no prompts. The visitor got the ticket, so I have direct evidence that these instructions were clear enough for this task.

**Reviewer B · cites p1**

The trial tells me that this visitor succeeded. Before I give credit, I would also want a degree in technical writing. A single successful visit cannot tell me where Ravi learned to produce instructions.

Before opening the answer, name the standard each reviewer used and point to the words each one relied on.

### How to read the evidence

Both reviewers read the same trial. A asks whether the visitor succeeded unaided, exactly the test the panel published. B moves from the visitor’s performance to Ravi’s formal qualification. Publishing a degree requirement would change the exercise. The file gives no basis for assuming that Ravi has, or lacks, that degree.
